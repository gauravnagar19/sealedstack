# Maintainer documentation

> **Maintainers.** These pages are for people (and agents) **changing sealedstack itself**.
> They are not instructions for setting up or running a sealedstack infrastructure, and
> parts describe designs that were later changed. To use sealedstack, start at
> [docs/](../README.md).

| Page | What it is |
|---|---|
| [Architecture](architecture.md) | The implementation-level design. |
| [Design spec](spec.md) | The original architecture and contracts. Where it disagrees with [the user experience](../user-experience.md), the user experience wins. |
| [Decision log](decisions.md) | Every decision, why, and what was rejected. Superseded entries stay in the log. |
| [Development](development.md) | Repo layout, tooling and the CI pipeline. |
| [Adding a provider](adding-a-provider.md) | The recipe for a new registry implementation. |

Also at the repository root: [CONTRIBUTING.md](../../CONTRIBUTING.md) and
